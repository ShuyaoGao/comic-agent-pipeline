    手机上怎么操作

    竖屏打开。顶部一行：标题、模式标签、☰ 菜单（3D 导演台、说明、退出）。上方是这一阶段的产物，阶段步骤条可以左右滑； 往下是输入创意、seed、成本档和按钮。「观看」模式下过程面板紧跟在产物下方；「我来编 / 练习」里点「看过程面板」全屏展开，点「返回」关闭。

    这是什么

    一个漫剧（短视频漫画剧）生产流水线的离线演示：一句创意 → 9 个 Agent（选题、编剧、审稿合规、角色设定、分镜、导演台、美术、合成、质检） → 剧本、角色、分镜表、导演台俯视图、分镜卡、草样片、质检报告、成本估算。每个 Agent 读写同一份结构化 JSON（右栏“共享状态”）。

    全部离线：文字由离线编造器按规则确定性生成（不是真实大模型）；图片是占位卡片，配音是提示音，草样片是轮播。 它们演示的是工程闭环、角色一致性机制、成本权衡，不是画质。

    三个模式

    • 观看：自动用示例创意逐个阶段跑一遍，左边看产物、右边看流程和共享状态怎么“长出来”。
    • 我来编：输入自己的创意、改 seed、换成本档；一键跑完或单步；从任一阶段重跑；导入 3D 导演台的镜头。
    • 练习：按任务清单做，完成一项自动打勾。

    右栏四个标签

    • 共享状态 JSON：刚写入的阶段会高亮。点阶段名展开 / 收起。
    • 一致性矩阵：每个镜头 × 4 项检查（seed 复用、参考图复用、固定外貌写进提示词、负面词抑制漂移）。
    • 成本与调度：若改用真实云端模型生产本片约花多少钱，以及“只给关键镜出真实视频”能省多少。单价全是示意值。
    • 生成日志：每次生成记一条：模型、提示词、seed、token（估算）、成本。

    两组预设档位

    • 成本档：省钱 / 标准 / 高质量 / 全量真实视频（只影响估算，不影响离线结果）。
    • 速度：逐段讲解 / 正常 / 快速 / 瞬间。
